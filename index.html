실습 1 AI가 먼저 질문하게 하기
나는 상품이나 서비스를 홍보할 때마다 비슷한 안내 이미지를 만들고 있어. 사진, 상품명, 장점, 가격, 문의 정보를 입력하면 같은 디자인 형식으로 홍보 이미지를 만드는 앱이 필요해. 아직 코드는 작성하지 마. 개발 전에 꼭 결정해야 할 내용을 최대 3개만 질문해줘. 답변을 받은 뒤 1장 분량의 PRD 초안을 작성해줘. PRD에는 목적, 사용자, 입력, 필수 기능, 제외 기능, 디자인 기준, 완료 기준을 넣어줘. 내가 승인하기 전에는 개발을 시작하지 마.
AI의 질문에는 강사가 공통 예시(온스튜디오)로 답변. 수강생별로 다르게 답하지 않음.

실습 2 확인한 PRD로 개발 시작
지금 확인한 PRD를 최종 기준으로 개발해줘. 먼저 구현 순서를 짧게 설명한 뒤, 필수 기능만 포함한 첫 버전을 만들어줘. - 가능하면 HTML 파일 하나로 실행되게 만들어줘. - 외부 이미지, 폰트, AI API는 사용하지 마. - 글자와 버튼은 크고 읽기 쉽게 만들어줘. - 요청하지 않은 기능은 추가하지 마. - 정해지지 않은 중요한 사항은 임의로 정하지 말고 질문해줘. 완성 후 파일 위치와 실행 방법을 쉽게 설명하고, 완료 기준별로 확인한 것과 확인하지 못한 것을 구분해서 알려줘.

실습 3 고객 입장에서 고치기
현재 앱의 다른 기능은 유지해줘. 고객이 무엇을 판매하는지 먼저 이해할 수 있도록 사업명보다 상품·서비스명이 더 잘 보이게 수정해줘. 가격 안내, 행동 문구, 문의 정보도 아래쪽에서 한눈에 읽을 수 있게 정리해줘. 새 기능은 추가하지 말고, 기존 사진 선택, 입력 반영, 이미지 저장 기능은 유지해줘. 수정 후 짧은 상품명과 긴 상품명을 각각 넣어 확인해줘.

문제가 생기면 증상을 그대로 알려주기
이미지 저장 버튼을 눌렀는데 저장된 파일에서 사진이 빠져 있어. 현재 미리보기와 저장된 이미지를 비교해서 원인을 찾아줘. 다른 기능은 유지하고 이 문제만 수정해줘. 수정 후 사진과 글자가 모두 포함된 이미지가 저장되는지 확인해줘. 확인하지 못한 부분은 확인했다고 말하지 마.
